# Stage 5 — Team Page Usability

Scope for this functional increment:

- Move team-page Back navigation out of the upper-right header into a fixed low thumb-zone action bar.
- Increase muted/supporting typography on overview, schedule, standings, and roster views.
- Render standings as separate returned groups/divisions instead of one long undifferentiated table when the provider supplies grouped standings.
- Add team-themed jersey-number badges to roster rows using lightweight CSS, not image assets.
- Preserve the Stage 4 card layout, team customization, live data, schedule, roster, standings, contextual Back behavior, and no-dead-control build law.
- Keep deeper roster biographical data and full team-page cosmetic theming deferred.
